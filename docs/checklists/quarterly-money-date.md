# The quarterly money date

Print one copy per quarter. Fill by hand while the [money date](../money-dates.md) happens. The meeting exists to fill this page; the page exists so next quarter's you starts with facts.

**Date of this sitting:** ______________________
**Quarter being reviewed:** ______________________
**Coffee/snack status:** ______________________

## Sprint 0: arrive (5 min)

- [ ] Calendar opened — is the next money date **already scheduled**? (Yes is the only passing grade.)
- [ ] Ledger open · bank + card sites open · all `Uncategorized` acceptable to begin
- [ ] Timer set: 90 minutes, or the [gentle version](../money-dates.md): three 10-minute sprints whenever energy exists

## Sprint 1: close the books (15 min)

- [ ] Ledger current through today; sweeps done
- [ ] Bank balances and ledger agree (both pots)
- [ ] Numbers, written right here:
  - **Quarter income:** $ ____________
  - **Quarter expenses:** $ ____________
  - **Quarter net profit:** $ ____________
  - **Profit year-to-date:** $ ____________

## Sprint 2: feed the tax pot (10 min)

- [ ] Set-aside percentage for the year: ________ % (from the [taxes chapter](../taxes.md) — mine lives at the top of the round range)
- [ ] **Amount moved to pot 2 this sitting:** $ ____________  *(move it now, not after the date)*
- [ ] **Tax pot running balance:** $ ____________
- [ ] Estimate due before next money date? **April / June / September / January** (circle), payment made or scheduled: [ ]
- [ ] Profit pattern changed this quarter? (big up / steady / low) → percentage adjustment noted? [ ]

## Sprint 3: the subscriptions ledger (10 min)

- [ ] Every recurring charge judged — keep / downgrade / kill decision recorded per charge
- [ ] Ongoing subscription count: ________ (aim: smaller than last quarter)
- [ ] Money reclaimed this sitting: $ ____________

## Sprint 4: the corners (10 min)

- [ ] Insurance: renewals visible, no policy expiring without a decision ([insurance starters](../insurance.md))
- [ ] New kind of risk acquired this quarter (new product, new venue, new contract)? → quote/update note: [ ]
- [ ] Anniversary month coming? → [the annual-report ritual](../annual-report.md) scheduled
- [ ] Registered agent / any SOS letter this quarter? What arrived: ______________________
- [ ] Any [professional trigger](../professionals.md) from chapter eight? → which one: ______________ → booked for this week: [ ]

## Sprint 5: one improvement move (15 min)

- [ ] The move: ______________________________________________
- [ ] Due date (inside next quarter): ______________
- [ ] First (tiny) step taken or scheduled today: [ ]

## Sprint 6: next quarter's goal (10 min)

- [ ] The one goal/number for next quarter (revenue, expense ratio, pot target, milestone): ______________________
- [ ] How last quarter's goal did (write it honestly): ______________________________________________

## Sprint 7: the kind sentence, and out (5 min)

- [ ] One thing that went right, written down: ______________________________________________
- [ ] Next money date confirmed on the calendar with a reminder: [ ]
- [ ] This page filed in the quarter folder, where [year-end](year-end.md) and the tax prep will find it

---

*Low-energy note: sprints 1, 2, and 7 are the three-sprint gentle version. If today only those happened, the date counted — the streak stays alive.*
